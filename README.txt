SHAHD WEBSITE — PROFESSIONAL GITHUB EDITION

الموقع في ملف واحد فقط:
- index.html يحتوي على كل التصميم والألوان والحركات.
- صورة شهد الأصلية مدمجة داخل الصفحة نفسها.
- لا تحتاج إلى رفع مجلد assets أو ملفات CSS أو JavaScript.

طريقة النشر على GitHub Pages:
1) فك ضغط ملف ZIP.
2) افتح المستودع على GitHub.
3) Add file > Upload files.
4) ارفع index.html مباشرة إلى جذر المستودع (Root).
5) اضغط Commit changes.
6) Settings > Pages.
7) اختر Deploy from a branch، ثم main و /(root)، وبعدها Save.
8) انتظر رابط الموقع في صفحة Pages.

ملاحظة: الموقع لا يحتاج إلى قاعدة بيانات. تحميل خطوط Cairo وPlayfair Display يحتاج اتصال إنترنت؛ وتوجد خطوط بديلة على الجهاز إذا لم يتوفر الاتصال.
